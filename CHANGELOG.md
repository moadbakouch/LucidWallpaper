# Changelog

Every release of LucidWallpaper, newest first. Downloads are on the
[Releases](https://github.com/moadbakouch/LucidWallpaper/releases) page.

## 0.5.0 (2026-11-13): A redesigned app

### New first-run setup
- An animated welcome: the icon lands with a chime and the name writes in.
- Pick your first wallpaper from a grid. A click applies it to the desktop right away.
- Choose open at login, pause on battery, global shortcuts and interface sounds up front.
- Optional screen saver install, then a short finish screen.
- Replay it any time from **Settings ▸ General ▸ Replay Welcome Setup**.
- The chimes are generated by the app. Turn them off with **Settings ▸ General ▸ Interface sounds**.
- Honors Reduce Motion.

### Redesigned main window
- Sidebar shows how many wallpapers are in each section, with a now-playing card (pause and
  next) at the bottom.
- Search, add, sort and filter live in the toolbar.
- Larger wallpaper cards with a Live badge, a hover Apply button and a selection ring.
- Wallpaper details moved to an inspector on the right (⌥⌘I to show or hide). This fixes the
  detail panel being cut off at smaller window sizes.
- Applying from the library now crossfades.
- The window opens larger (1280 × 780).

### Store
- Category chips and larger previews that fill their frame.
- One Apply button per card, with a download or in-library indicator beside it.
- The Store catalog now loads from this repository, so it updates without an app update.
  The previous feed address had stopped working.

### Settings
- Colored icons in the sidebar and a tidier About row.

### Fixes
- **Check for Updates** now points at this repository. It could not find updates before.

## 0.4.0 (2026-11-12): Store fixes and the Creator

### Store wallpapers fixed
Most community (Lively) wallpapers were written for Chromium on Windows and broke when loaded
from `file://` on macOS. Wallpapers now run in a macOS web runtime:
- Each package is served from its own `lucidwp://` origin, so local `fetch()`, ES modules and
  WebGL textures work. Windows-style paths and wrong-case file names resolve.
- Dates and clocks render in English, even when a wallpaper hard-codes another language.
- Weather wallpapers get an approximate location instead of a denied permission prompt.
- Settings files with comments or trailing commas keep all their controls; folder (image
  picker) and button controls are supported.
- A crashed web page reloads instead of leaving the desktop blank.
- The screensaver and thumbnails use the same runtime.

Every Store wallpaper was downloaded, rendered and checked on a Mac. 15 that still did not work
were removed; 82 remain.

### New: Create
**File ▸ Create Wallpaper (⌘N)** or **Create** in the sidebar, with a live preview.
- Start from 9 looks or your own photo.
- Background: flowing gradient, solid color, photo (slow zoom) or video, plus blur, dim and
  parallax.
- Effects: snow, rain, stars, fireflies, bubbles, cherry petals, constellation, code rain, bokeh.
- Clock, date and your own text, with fonts, positions and a glass-card style.
- Creations are normal Lively packages: tweak them in the inspector or reopen them with
  **Edit in Creator**.

### Also
- Separate Settings window and a Widgets page in the library.
- Custom global hotkeys, Shortcuts / App Intents, ⌥-double-click desktop gestures.
- Per-display menu-bar color that blends with the wallpaper.
- Online image search (Wallhaven) in the Store.
- 120 fps on ProMotion displays; ambient sound ducks when other apps play audio.
- Interactive screensaver with the same live feeds as the desktop.

## 0.3.0: Multi-monitor, sound and polish

- **Displays:** visual monitor-arrangement map, per-display fit/zoom and pause, behaviour for
  newly connected displays, Apply split button.
- **Ambient sound:** the built-in macOS Background Sounds (rain, ocean, stream, fire, night,
  noise) or your own file; volume, mute, play/pause and skip in the menu bar.
- **Feedback:** in-app feedback form.
- **Liquid Glass** styling on macOS 26.
- Stability: fixed audio playing while paused, two crashes, and shader/web snapshots. Test
  harnesses now back up and restore your library.
- Removed: AI shader generation.

## 0.2.0: New wallpaper kinds and living wallpapers

- **New kinds:** Metal shaders, images, animated GIFs, photo slideshows (Ken Burns +
  crossfade), web pages.
- **Library and UI:** real previews, favorites, tags, profiles, playlist and schedule rotation;
  sidebar Settings; native main menu and Playback shortcuts (Pause ⌘P, Next ⌘], Previous ⌘[,
  Random ⌘R); command palette (⌃⌥⌘Space); global hotkeys; onboarding.
- **Living wallpapers:** weather, time-of-day and theme feeds for web wallpapers (no location
  permission needed); system stats and now-playing feeds; desktop overlay widgets; per-Space
  wallpapers; ambient sound; global dim; idle / meeting / Reduce Motion pause.
- Installable screensaver.

## 0.1.0: First version

- Wallpapers render behind the desktop icons on every display and every Space.
- Looping video wallpapers (Fill / Fit / Stretch with zoom).
- Interactive web wallpapers with the cursor bridged in, plus the Lively JS API.
- Lively package import (`.zip` or folder), with `LivelyProperties.json` shown as live controls.
- Library window, persistence, restore on launch.
- Pauses when the desktop is covered, on lock and sleep, and optionally on battery.
